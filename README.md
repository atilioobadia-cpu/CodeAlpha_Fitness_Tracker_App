# Fitness Tracker App

A simple mobile-first fitness tracker for CodeAlpha Day 01 Task 3. Log workouts, steps, and calories manually, then review daily totals and a seven-day steps chart. Activity records are saved in browser local storage.

## Built with

- HTML, CSS, and vanilla JavaScript
- Nunito with system font fallbacks
- Teal design system with no shadows or gradients
- Local storage for activity records

## Files

- `index.html` — dashboard, activity list, entry sheet, and styling
- `app.js` — activity logging, daily and weekly totals, and persistence

## Run

Open `index.html` in a modern browser. No build step or server is required. Google Fonts needs an internet connection; the system font fallback works offline.
